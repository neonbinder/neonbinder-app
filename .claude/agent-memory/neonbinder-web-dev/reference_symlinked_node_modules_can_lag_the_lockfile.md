`link-deps.sh` can refuse in the wrapper layout, so a worktree's `apps/web/node_modules`
is sometimes symlinked by hand to the primary checkout's. That install can be older than
the worktree's `package-lock.json`. Symptom: `npm run build` fails with "failed to resolve
import <pkg>" from a file you never touched, and one `lib/` test fails on a missing package.
Check `ls node_modules/<pkg>` and `grep <pkg> package.json` before suspecting your diff; report
it as an environment red, do not work around it in code.
