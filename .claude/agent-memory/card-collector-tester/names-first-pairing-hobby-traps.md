Checks to run on any names-first pairing or variation-by-stem change (first seen NEO-591 review, 2026-11-18):

- A tie must stay with the operator. Anything that later "pre-keeps" or auto-numbers leftovers must skip tied cards, or both halves of one physical card are created (two SportLots "38 [VAR ...]" vs BSC 38b/38c with labels that differ is the common shape).
- "Names agree, numbers differ" is safe when the classes differ (OV-ANFI vs NNO, US12 vs 12). Two plain digit numbers that differ (38 vs 250) usually mean different cards of one player (base vs Highlights/Leaders subset, both lists incomplete) or two players sharing a name (Will Smith C/P). Ask for team agreement or a lower tier.
- Bare 38 against 38a is the expected relation under the "bare takes a" rule; flagging it "Numbers differ" is noise across whole 2021 Topps-style sets.
- Error/corrected pairs (616a ERR / 616b COR) break "bare takes a". Jason ruled (2026-11-18): no special case, follow the marketplace's lettering; the number picker is the escape hatch.
- Father/son and Jr./Sr. names (Griffey, Ripken, Tatis, Guerrero) when one source drops "Jr.".
- A link or chip that says "#38" on cards 38b/38c reads to a collector as a conflict unless it says the row covers every version.

- Settled 2026-11-18: two different plain digit numbers never pair automatically; 38 = 38a; letters beat NNO; every automatic number choice gets a preselected picker.
- Picker friction check: an "editable" default must not look like a demand. If the picker and its warning line show wherever the printed text differs (US12 vs 12, BCP-12 vs 12, 38 vs 38a), a whole Update or 2021 Topps-style set gets one per row. Put the warning and open radios only where the numbers really disagree; agreeing prints get a quiet, collapsed control.

**Why:** the wrong card linked to a listing means selling the wrong card; duplicates in a set need hand cleanup (sets are fixed, never deleted).
**How to apply:** walk each of these against the pairing core and anything downstream that acts on its leftovers. See [[pasted-checklist-format-traps]], [[retro-cards-set-year-is-not-card-year]].
